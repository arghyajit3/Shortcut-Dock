# Shortcut-Dock
A ShortCut Dock for PC(s) (Windows, Linux, Max) with customizable shortcut buttons and a volume control knob

## About this project
This is a Shortcut Dock that can be used on any PC whether Windows, MacOS or any Linux distribution.

### Components Used
1. Raspberry Pi Pico
2. KY-040 Rotatory Encoder
3. Push Buttons
4. Jumper Wires
5. 0.1uF Capacitors
6. 100uF Capacitors
7. 10k ohms Resistors
